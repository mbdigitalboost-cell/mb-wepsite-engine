# sections/

Bilinçli olarak boş.

Bu klasör, müşteriye özel sayfa bölümlerini barındıracak: `Hero`, `Services`,
`About`, `Testimonials`, `FAQ`, `ContactCTA` vb. Her müşteri brief'i
geldiğinde, o müşterinin sektörüne ve marka kimliğine uygun section
component'leri burada oluşturulur.

Şu aşamada (Website Engine V1 foundation) herhangi bir müşteriye özel
tasarım eklenmemiştir.
